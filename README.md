# Лабораторные работы по Java: Вычислительные методы

**Автор:** Пашко Святослав

## 📝 Описание проекта

Данный проект представляет собой набор из четырёх Java-приложений с графическим интерфейсом (Swing), демонстрирующих реализацию численных методов и визуализацию результатов. Сайт-портфолио не нужен — это десктопные приложения.

*   **HelloWorld** — учебный пример базовых конструкций Java (битовые операции, массивы, `switch`).
*   **LinearSystemsSolverApp** — решение систем линейных уравнений методами Холецкого и простой итерации.
*   **InterpolationApp** — интерполяция функций полиномом Лагранжа и параболическим сплайном с интерактивным графиком.
*   **NonlinearEquationSolverComplete** — решение нелинейных уравнений методами секущих и дихотомии с исследованием сходимости.

## 🛠 Используемые технологии

*   **Java 11+** — язык программирования (используются `switch`-стрелки, `String.repeat()`, лямбда-выражения).
*   **Java Swing** — построение графического интерфейса (окна, таблицы, графики).
*   **Java AWT** — обработка событий мыши и клавиатуры, работа с графикой (`Graphics2D`).
*   **Стандартная библиотека JDK** — без внешних зависимостей.

## 📁 Структура проекта

*   `HelloWorld.java` — учебный пример базовых конструкций.
*   `LinearSystemsSolverApp.java` — решение СЛАУ (Холецкий + простая итерация).
*   `InterpolationApp.java` — интерполяция (Лагранж + параболический сплайн).
*   `NonlinearEquationSolverComplete.java` — решение f(x)=0 (секущие + дихотомия).

## ⚙️ Функционал приложений

### 1. HelloWorld
Демонстрирует битовые операции, шифрование через XOR, работу с массивами и оба вида `switch`.

### 2. LinearSystemsSolverApp
1.  Ввод матрицы **A** и вектора **b** через таблицу (размер 2–100).
2.  **Методы:** разложение Холецкого (для симметричных матриц) и простая итерация.
3.  **Кнопки:** «Пример», «Сгенерировать», «Сравнить методы», «Очистить».
4.  Вывод невязки, времени решения и подробного лога.

### 3. InterpolationApp
1.  **Методы:** полином Лагранжа и параболический сплайн.
2.  Интерактивный график с масштабированием (колесо мыши) и панорамированием.
3.  Пошаговое решение на двух вкладках.
4.  Данные варианта 2 загружаются по умолчанию.

**Данные варианта 2:**

| X | 0.2 | 0.8 | 1.4 | 2.0 | 2.6 | 3.2 | 3.8 |
|---|-----|-----|-----|-----|-----|-----|-----|
| Y | -6.4 | -4.4 | 2.2 | 4.7 | 5.1 | 3.3 | 1.7 |

### 4. NonlinearEquationSolverComplete
1.  **Функции:** `2.2 - 2^x`, `x² - 2`, `sin(x) - 0.5`, `x³ - 2x - 5`, `ln(x) + (x+1)³`, `cos(x) - x - 2`.
2.  **Методы:** секущих и дихотомии.
3.  **Кнопки:** «Решить уравнение», «Исследовать сходимость», «Исследование точности», «Очистить».
4.  График функции с отметкой найденного корня.

## 🚀 Как запустить

1. Установите **JDK 11+**.
2. Скомпилируйте и запустите нужный файл:

```bash
javac HelloWorld.java && java HelloWorld
javac LinearSystemsSolverApp.java && java LinearSystemsSolverApp
javac InterpolationApp.java && java InterpolationApp
javac NonlinearEquationSolverComplete.java && java NonlinearEquationSolverComplete
```

Или скомпилировать всё сразу:

```bash
javac *.java
```

> ⚠️ Если файлы пришли с расширением `.txt` — переименуйте их согласно именам классов.
